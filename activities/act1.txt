C Programming Practice Activities

Topic Coverage: Loops • Integers • Strings • Dynamic Memory (malloc)
Purpose: Piscine / Technical Coding Preparation

🟢 LEVEL 1 – BASIC
Activity 1: String Length

Objective: Determine the length of a string.

Instructions:

Write a function that counts the number of characters in a string.

Do not use <string.h>.

Function Prototype:

int my_strlen(char *str);


Test Case:

Input:  "Hello"
Output: 5

Activity 2: Reverse an Integer

Objective: Reverse the digits of an integer.

Instructions:

Use loops only.

Do not convert the number into a string.

Example:

Input:  123
Output: 321

Activity 3: Count Vowels

Objective: Count the number of vowels in a string.

Instructions:

Count both uppercase and lowercase vowels.

Do not use string library functions.

Example:

Input:  "Education"
Output: 5

🟡 LEVEL 2 – INTERMEDIATE
Activity 4: Duplicate a String

Objective: Create a dynamically allocated copy of a string.

Instructions:

Use malloc.

Copy characters using loops.

Return NULL if memory allocation fails.

Function Prototype:

char *my_strdup(char *src);

Activity 5: Even and Odd Arrays

Objective: Separate even and odd numbers into two dynamic arrays.

Instructions:

Given an array of integers.

Create two new arrays using malloc.

Print both arrays.

Example:

Input:  [1, 2, 3, 4, 5]
Even:   2 4
Odd:    1 3 5

Activity 6: Longest Word

Objective: Identify the longest word in a sentence.

Instructions:

Words are separated by spaces.

Do not use string library functions.

Example:

Input:  "C programming is powerful"
Output: programming

🔴 LEVEL 3 – ADVANCED
Activity 7: Sort Strings

Objective: Sort dynamically allocated strings alphabetically.

Instructions:

Read N strings from input.

Store them using malloc.

Implement your own string comparison.

Sort using any algorithm.

Activity 8: Remove Duplicate Characters

Objective: Remove repeated characters from a string.

Instructions:

Return a newly allocated string.

Preserve the original order.

Do not use <string.h>.

Example:

Input:  "banana"
Output: "ban"

Activity 9: Implement atoi

Objective: Convert a string into an integer.

Instructions:

Handle optional + or -.

Stop at first non-digit character.

Use loops only.

Function Prototype:

int my_atoi(char *str);


Example:

Input:  "-123abc"
Output: -123

✅ Rules Reminder

No <string.h> unless stated

Always check malloc

Free allocated memory

Use loops (for / while)

Write clean and readable code
