# 🎮 STRING ADVENTURE: “Escape the Broken Program”

## 🟢 EASY – *Code Detective Missions*

---



### 🕵️ Mission 2 – Copy Cat Gone Wrong

**Objective:** Practice string copying

**Story:**
A copying robot forgot something important.

**Task:**
Fix a broken string copy function.

**Requirements:**

* Copy character-by-character
* Ensure correct termination
* Do not use built-in functions

---

### 🎯 Mission 3 – Vowel Hunter Game

**Objective:** Character comparison and counting

**Task:**
Count vowels and compute a score:

* a = 1
* e = 2
* i = 3
* o = 4
* u = 5

**Example Output:**

```
Score: 11
```

---

## 🟡 INTERMEDIATE – *Build & Play Challenges*

---

### 🧩 Challenge 1 – Secret Word Generator

**Objective:** Dynamic memory allocation

**Task:**

* Ask the user for a length
* Allocate memory using `malloc`
* Fill the string with characters

**Constraint:**

* No repeated letters allowed

---

### 🔄 Challenge 2 – Mirror Machine

**Objective:** String manipulation

**Task:**
Reverse a string and display both versions.

**Example:**

```
hello | olleh
```

**Bonus:**
Check if the string is a palindrome

---

### 🧪 Challenge 3 – String Fusion Lab

**Objective:** Understand indexing and merging

**Task:**
Merge two strings alternately

**Example:**

```
abc + XYZ → aXbYcZ
```

---

## 🔴 HARD – *Boss Level Problems*

---

### 💣 Boss 1 – Clone Machine

**Objective:** Safe dynamic memory usage

**Task:**

* Duplicate a string using dynamic memory
* Print both original and copy

**Requirement:**
Modifying the copy must not affect the original

---

### ✂️ Boss 2 – String Cleaner 3000

**Objective:** In-place string modification

**Task:**
Remove:

* spaces
* numbers

**Example:**

```
Input:  "c0 str1ng 123"
Output: "cstring"
```

---

### 🧠 Boss 3 – Word Token Arena

**Objective:** Advanced pointers and memory handling

**Task:**

* Split a sentence into words
* Store each word dynamically

**Output Requirements:**

* Print all words
* Print longest word
* Print shortest word
